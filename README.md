# Sociality — First In-Chat Version (Source Code)

This is the **first, simple cream-colored board** edition that preceded the illustrated tabletop browser game, glow effects, and hovering cards. It was recreated from the first ChatGPT playable design so that you can run it as a normal HTML page.

## Run the game

1. Unzip this folder.
2. Open `index.html` in Chrome or Edge.
3. Start with choice 1A or 1B.

No installation, server, dependencies, or internet connection required.

## Files

- `index.html` — the HTML markup, board SVG, and buttons
- `styles/game.css` — visual styles and responsive design
- `js/game.js` — card decisions, collected concepts, Jokers, and interface updates
- `original-standalone.html` — the same game in one self-contained file, as previously delivered

## Development context

This version was a functional proof of concept: the original Sociality rules and card choices were implemented first. Later browser versions moved to the photographed original board and added card visuals and animated effects.

**Note:** This is the source from the **standalone recreation of the first in-chat prototype**, not an export of ChatGPT's original interface code.
